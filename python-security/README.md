## Scripts

### log-analyzer.py
Parses authentication logs to detect brute force patterns.
- Extracts failed login attempts using regex
- Flags IPs exceeding a configurable attempt threshold
- Generates a security report with top targeted usernames

**Run:**
```bash
python3 log-analyzer.py
```

## Security Relevance
These scripts demonstrate Python automation applied to security operations — log parsing, pattern detection, and anomaly flagging are core skills for Blue Team analysts and SOC roles.
